The tagged component releases contain the validated binaries. Put vkd3d-proton and DXVK DLLs in the game directory, never in the shared Steam prefix `system32`. Install both MoltenVK filenames in `runtime/wine/lib/moltenvk-vkmt/`; the Wine directory keeps `libMoltenVK.dylib` as a link to `libMoltenVK.1.dylib`.

The MetalSharp release includes the backend built from this branch. The MoltenVK branch pins the matching SPIRV-Cross commit and contains its build command in `METALSHARP_BUILD.md`. No shader replacement, shader skip, or draw drop is enabled.

Validation covered cold and warm vkd3d caches, 80 captured tessellation shaders, world rendering, movement, and attacks. The logs contained no Metal shader compilation failure, primitive-restart warning, device loss, invalid resource, or page fault.
